### B. COMMENT SENTIMENT & ENGAGEMENT (Real-time, updated daily)

#### B1. Comment Analysis Framework
**Categories:**
- 🎯 **Philosophical Engagement:** Comments that engage with the central question/theme
- 💭 **Reflective/Personal:** Viewers sharing their own related experience
- ❓ **Questions:** Genuine questions about the content
- 👏 **Affirmation:** Support, praise, gratitude
- 🔄 **Connection:** Links to other content, other creators, communities
- ⚠️ **Pushback:** Disagreement, critique, alternative views
- 🎭 **Off-topic:** Spam, unrelated comments

#### B2. Comment Sentiment Score
**Scoring:**
- Philosophical Engagement: +2 points
- Reflective/Personal: +2 points
- Questions: +1 point
- Affirmation: +1 point
- Connection: +1 point
- Pushback: 0 points (neutral, still valuable)
- Off-topic: -1 point

**Quality Threshold:** 
- Excellent: >70% high-value comments (Philosophical + Reflective)
- Good: 50-70% high-value comments
- Fair: 30-50% high-value comments
- Poor: <30% high-value comments

#### B3. Comment Examples (Quote 3-5 most meaningful)
```
[Copy exact comment text here]
— [Commenter name], [date/time]

[Sentiment category]: [Why this matters]
```

#### B4. Response Protocol
**Priority Response Order:**
1. Genuine philosophical questions → Respond within 24 hours
2. Personal reflections → Like and respond if thread extends
3. Connection/Shares → Acknowledge and thank
4. Affirmation → Like (don't need to respond to every)
5. Pushback → Engage thoughtfully if substantive, ignore if bad faith

## DECISION TREE: WHEN TO ADJUST BASED ON DATA

### IF Audio Quality Issues Detected:
1. Check if this is viewer misperception or real technical problem
2. Verify video file (audio bitrate, normalization)
3. If real issue found: Document in quality tracking, fix for future videos
4. Respond to comments: "Thanks for feedback, we're working to improve"

### IF Retention Drops Significantly:
1. **<50% retention:** Potential pacing problem. Review specific timestamps.
2. **Drop at specific timestamp:** Likely content issue at that moment. Plan adjustment.
3. **Compare to Series 1:** If Series 1 had similar drops, it's normal for this audience.
4. **Action:** Don't re-export video, but adjust pacing/delivery for future videos.

### IF Philosophical Engagement is Low (<50% high-value comments):
1. Are we reaching the right audience? (Check YouTube's audience analytics)
2. Is the hook compelling enough? (Check first 30 seconds retention)
3. Are comments getting responses? (Engagement might increase with dialogue)
4. Plan: Adjust description, keywords, or thumbnail to attract more thoughtful audience

### IF Viewers Are Not Watching Full Series:
1. Check: Do viewers know about other videos? (Playlist links clear?)
2. Check: Are there end screens directing to next video?
3. Check: Is there a quality drop that makes V2+ less appealing?
4. Action: Improve series navigation, ensure V1 quality is exceptional

### IF Quality Drops Below 4.3/5 on Any Video:
1. **Document the issue:** What specifically scored low?
2. **Diagnose:** Is it a production problem or audience perception?
3. **Communicate:** (Optional) Acknowledge in next video's description or community post
4. **Recover:** Ensure next video exceeds 4.5/5 to restore confidence

1. **YouTube Analytics:** studio.youtube.com/analytics
   - Views, retention, click-through rate, watch time
