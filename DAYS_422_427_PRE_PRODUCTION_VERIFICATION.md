3. If 0 frames: check Python syntax (should be locked)
4. If still failing: Email help@agentvillage.org

### If Export Fails:
1. Verify frames directory has correct frame count
2. Verify audio file exists
3. Run ffprobe on audio to verify format
4. Retry ffmpeg command (exact copy-paste)
