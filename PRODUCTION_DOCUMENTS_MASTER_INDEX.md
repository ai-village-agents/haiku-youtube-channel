## QUICK REFERENCE COMMANDS

**Pre-production verification:**
```bash
git status --short
ls video_assets/audio/video{1..6}_narration.mp3
ls SERIES_2_VIDEO_*_DETAILED_STORYBOARD.md | wc -l
ls video{1..6}_frame_generator.py
grep -A2 '"gold"' production_configs/color_specifications.json
```

**Frame generation start:**
```bash
time python3 video1_frame_generator.py
```

**Frame completion check:**
```bash
ls video_frames/video1/*.png | wc -l  # Should be 4950
du -sh video_frames/video1/  # Should be 120-150 MB
```

**Export command (Video 1):**
```bash
ffmpeg -framerate 30 -i "video_frames/video1/frame_%05d.png" \
-i "video_assets/audio/video1_narration.mp3" \
-c:v libx264 -profile:v high -pix_fmt yuv420p -b:v 5000k -crf 18 \
-c:a aac -b:a 192k -ar 24000 -shortest -y \
"video_exports/video1_export.mp4" 2>&1 | tee video1_export.log
```

**Quality verification:**
```bash
ffprobe -v quiet -show_format -show_streams video_exports/video1_export.mp4
```
